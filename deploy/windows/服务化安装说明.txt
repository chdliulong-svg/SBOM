========================================================================
  变桨系统Service BOM - Windows 系统服务化部署指南 (无人值守 / 开机自启)
========================================================================

本方案使用经过工业级验证的 WinSW (Windows Service Wrapper) 将系统包装为系统底层服务：
- 开机即自动在后台启动，无需登录 Windows 桌面；
- 彻底告别命令行黑窗口，避免操作人员误关闭；
- 进程意外崩溃时自动秒级重启自愈；
- 日志自动重定向至 logs/app.log 并自动按大小轮转。

【一键安装步骤】：
1. 从 WinSW 官方 Releases 下载 WinSW-x64.exe (例如版本 2.12.0)：
   https://github.com/winsw/winsw/releases
2. 将下载的 WinSW-x64.exe 复制到本目录 (deploy\windows\)，并重命名为：
   service_bom.exe
   (即确保与本目录下的 service_bom.xml 同名同路径)
3. 鼠标右键以【管理员身份运行】执行以下命令：
   service_bom.exe install    -> 安装系统服务
   service_bom.exe start      -> 立即启动服务
   service_bom.exe status     -> 查看运行状态
   service_bom.exe stop       -> 停止服务
   service_bom.exe uninstall  -> 卸载服务

服务安装完成后，可在 Windows 的【服务管理】(services.msc) 中看到：
名称：变桨系统Service BOM 协同管理服务 (ServiceBOMServer)
启动类型已自动设置为【自动】。
